ISO 13616 · International Bank Account Number

Anatomy of an IBAN

Every IBAN is a country code, two check digits and the account number used inside that country. The check digits are computed from everything else, so almost any typo makes them stop matching.

The check digits

How the check digits catch mistakes

The check is ISO 7064 MOD 97-10. It turns the whole IBAN into one large number and divides it by 97. A correct IBAN always leaves a remainder of exactly 1. These are the steps for the IBAN above.

  1. Move the first four characters to the end

  2. Replace each letter with a number

    A becomes 10, B becomes 11, and so on up to Z, which becomes 35.

  3. Divide by 97, nine digits at a time

    The number is too long for ordinary arithmetic, so the remainder is carried into the next chunk. Grey digits are the carried remainder.

  4. The remainder must be 1
